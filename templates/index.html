Importar horario desde Excel

Subí un Excel con el horario de un mes ya armado. El sistema leerá los turnos, actualizará la base de datos con empleados nuevos y guardará el estado final de cada trabajador para generar el mes siguiente correlativamente.

📊
Arrastrá tu Excel aquí
o hacé clic para seleccionar (.xlsx, .xls)

Resultado de la importación

ℹ️ Formato esperado del Excel

El archivo debe tener el mismo formato que el horario que mostraste:
• Una celda con el nombre del mes y año (ej: "abril 2026")
• Una fila con los números de días (1, 2, 3 … 30)
• Filas de empleados con nombre en la primera columna
• Celdas con valores: 14:00 (AM) · 6:00 (PM) · 22:00 (Noche) · L (libre)
• Los colores de celda también son reconocidos automáticamente
